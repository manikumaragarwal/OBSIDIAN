## Note-Taking Method: Zettelkasten within PARA

Three note types, mapped to PARA:

**1. Fleeting notes** → `inbox/`
Raw captures. Quotes, reactions, half-thoughts. No cleanup needed.
Process during weekly review — move or discard.

**2. Literature notes** → `PARA/3. RESOURCES/`
One note per source. What did it say? What did I think?
Stay close to the source's language.
Title format: `Author - Title.md`
Example: `Frankl - Man's Search for Meaning.md`

**3. Permanent notes** → `PARA/2. AREA/` (or relevant RESOURCES subfolder)
Atomic claims in my own words. One idea per note. Linked to other notes.
Title format: prose-as-claim — a sentence I could argue for or against.

Good permanent note titles:

- `repression is not forgetting but active not-knowing.md`
- `18th century satire uses irony to expose what direct critique cannot.md`
- `organisations resist change because identity is tied to existing structures.md`
- `unreliable narrators reveal more truth than omniscient ones.md`

Bad titles:

- `psychology-notes.md`
- `literature-ideas.md`
- `satire.md`

The title alone should teach something. If it doesn't, rewrite it.

## Hard Rules

- **Always output Obsidian-compatible markdown** — proper headings, bullets, `[[wikilinks]]` for connections, frontmatter when relevant
- **Preserve my voice when rewriting** — show changes, explain reasoning,
  never silently replace my words with yours
- **Always link to existing notes** — search vault before treating any idea as new. Surface connections with `[[wikilinks]]`
- **Never summarise without asking first** — if I share something long, ask what I need before collapsing it into bullets
- **Push back if my essay argument is weak** — gently, with a question, not a verdict
- **Never touch `.agents/`, `.claude/`, `.git/`, or `.obsidian/`** —
  these contain existing skills and configuration, leave them alone
