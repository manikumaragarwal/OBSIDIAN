# Nano Banana Automation: Scaling Style-Consistent Image Generation Using Zapier And Gemini

The core of scaling creative output is moving from manual prompting to automated agentic systems. By using Gemini to learn from reference styles and connecting it to Zapier, teams can generate consistent, high-quality images from simple spreadsheet entries.

## Breakdown
1. **Level 1 (Noob):** Manually entering prompts into Gemini every time—results in inconsistent and "ugly" images.
2. **Level 2 (Pro):** Uploading reference styles to Gemini, asking it to learn and turn them into a system prompt, then creating a "Gem" with these specific instructions.
3. **Level 3 (Legend):** Connecting Gemini with Zapier and a spreadsheet. A team member adds an idea to the sheet, Gemini triggers Nano Banana with the style-trained system prompt, and the image link is added back to the sheet automatically.

## Tool Stack
- **Gemini (Google):** For style learning and prompt generation.
- **Zapier:** For workflow orchestration between sheets and AI.
- **Nano Banana:** For image generation.
- **Google Sheets:** As the team-facing interface for scaled input.

## The Why
Legends focus on building systems that scale for teams, not just for themselves. Automation removes the "creative bottleneck" by ensuring the AI always adheres to a pre-defined brand style without requiring a prompt engineer for every single task.
