# Figma Auto Layout: The Visual Vocabulary For Successful Vibe Coding And Front-End Engineering

The fastest way to get better at vibe coding is not learning how to prompt, but mastering Figma's Auto Layout. Because Auto Layout is based on the literal rules of front-end code, mastering it provides the technical vocabulary needed to fix AI-generated layouts when they inevitably break.

## Breakdown
1. **Code-Logic in Design:** Auto Layout rules (stretching, fixed widths, hugging content, nested containers) are the exact rules that govern CSS Flexbox and container behavior.
2. **The Prompting Gap:** Designers fail at vibe coding because they don't know the vocabulary for what is broken. They "prompt into the ether" instead of giving specific structural instructions.
3. **Visible Rules:** Auto Layout makes invisible code rules visible. Once you see them in Figma, you can see them in your code and in the AI's logic errors.

## Tool Stack
- **Figma:** Specifically the Auto Layout panel.
- **Cursor / Claude Code:** For executing the structural prompts learned in Figma.

## The Why
Vibecoding is fast but fragile. When a layout breaks, the AI's standard "Let me adjust that" response often makes things worse. By understanding Auto Layout, you gain the technical authority to tell the AI *exactly* how to nest a container or fix a stretch, moving from a "prompter" to an "engineer."
