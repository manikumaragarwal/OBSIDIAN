# Claude Code Lead Magnet Automation: A 3-Step Viral Workflow Using Apify, N8n, and Notion MCP

Going viral is only half the battle; capturing that attention into a lead magnet is what builds a business. This workflow automates the creation of unique, transcript-based guides for every video you post, allowing you to deliver value to commenters instantly via Claude Code.

## Breakdown
1. **Scrape:** Use **Apify** to allow Claude Code to scrape your latest video and pull the transcript.
2. **Generate:** Use Claude to transform the raw transcript into a "completely unique lead magnet" (a guide or PDF based on the video's topic).
3. **Automate & Upload:** Use **N8n** for common automations and the **Notion MCP server** to upload the final guide to Notion, providing a shareable link for commenters.

## Tool Stack
- **Claude Code:** The central orchestrator.
- **Apify:** For video scraping and data extraction.
- **N8n:** For workflow automation between apps.
- **Notion MCP:** For direct document creation and sharing.
- **Playwright:** To allow Claude to interact with browser-based tools like N8n.

## The Why
This creates a "Lead Magnet Engine." Instead of manually building a guide for every reel, the AI reads what you said, writes the guide, and hosts it on Notion in one loop. This ensures that every viral moment is immediately monetized or captured.
