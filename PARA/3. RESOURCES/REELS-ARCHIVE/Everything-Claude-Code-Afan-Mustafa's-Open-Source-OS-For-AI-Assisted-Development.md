# Everything Claude Code: Afan Mustafa's Open-Source OS For AI-Assisted Development

Anthropic hackathon winner Afan Mustafa has open-sourced his "Everything Claude Code" setup, transforming the terminal into a plug-and-play operating system for AI development. This setup uses 11 specialized agents and continuous learning to automate the entire dev cycle from planning to testing.

## Breakdown
1. **Specialized Swarm:** 11 agents work together (Planning, Architecture, Security, Go Review, Playwright Testing, etc.).
2. **Pattern Recognition:** The system reads your git history to learn your specific coding style and turns patterns into reusable skills with confidence scores.
3. **Seamless Integration:** Pre-built MCP configs for GitHub, Supabase, Vercel, and Railway are wired together out of the box.
4. **Cross-Platform:** Works on Windows, Mac, and Linux as a single Claude Code plugin.

## Tool Stack
- **Claude Code:** The central engine.
- **Zenith Chat:** The case study application built in under a day using this setup.
- **GitHub (Everything Claude Code):** The source repository.

## The Why
This repo marks the shift from "Chatting with AI" to "Running an AI Operating System." By automating the coordination of 11 specialized agents, a lone developer can achieve the velocity of a full engineering team while maintaining senior-level security and testing standards.
