# The AI Flash Cut Sequence: 60-Second Viral Visuals

A rapid workflow for creating complex, annotated flash cut sequences using AI tools to bypass manual Photoshop and masking labor.

## Breakdown
1. **Style Transformation**: Take a still image and upload it to an AI image generator (e.g., Nano Bonona). Prompt to "change style to a drawing with annotations."
2. **The Edit**: 
    - Insert the AI-generated drawing for exactly two frames.
    - Add a "negative filter" for two frames between each clip.
3. **AI Task Masking**: Use AI track masking tools to handle frame-by-frame masking instead of manual labor.

## Tool Stack
- Nano Bonona (AI Style Transformation)
- AI Track Masking (General Category)
- CapCut / InVideo (Final Assembly)
