# The Daily Content Researcher: Generating 100+ Trending Topics with Claude Code

A dual-agent system that automates the transition from "Raw Trend Data" to "Multi-Angle Content Ideas" using custom Claude Code skills.

## Breakdown
1. **The Researcher Skill**: Build a custom skill that scrapes Twitter, Reddit, and GitHub to pull all trending topics within a specific niche.
2. **The Ideator Skill**: Feed the scraped topics into a second agent that spins each individual topic into 5 different content angles.
3. **The Yield**: Identifying 20 trending topics a morning results in 100 high-relevance topics ready for production.

## Tool Stack
- Claude Code (Custom Skills)
- Scraping Tools (Twitter/Reddit/GitHub API or MCP)
- Multi-Angle Prompting Framework

## The Why
The system eliminates "Idea Fatigue" by delegating the heavy lifting of research and brainstorming to AI agents. It ensures that the content is always grounded in current market "heat" (trending topics) while providing the creative diversity needed to stay fresh.

## Script Spark
