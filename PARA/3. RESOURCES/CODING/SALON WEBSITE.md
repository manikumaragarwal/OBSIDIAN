# Prompt

Here’s a **single, copy-paste master prompt** in clean Markdown you can drop into any AI website/code generator.

---

# 🧠 MASTER PROMPT — Conversion-Focused Modern Indian Salon Website

## Objective
Design and build a **modern, premium, minimal, and highly conversion-focused salon website** for an Indian audience.

This website is **not a portfolio**.  
It is a **customer conversion machine** whose only job is:
> Turn visitors into bookings as quickly and smoothly as possible.

Every design decision must answer:  
**“Will this increase trust and make the user book an appointment faster?”**

---

## Understand Customer Psychology (Critical)
A typical visitor comes to the website to:
1. Check if the salon looks premium and hygienic
2. See services offered
3. Check prices
4. See real results (gallery / before-after)
5. Read reviews
6. Find location and booking method

---

## Design Language & Visual Style

- Minimal, elegant, clutter-free layout
- Large typography, generous whitespace
- Editorial, luxury brand feel (not local poster style)
- Soft luxury color palette suitable for Indian aesthetics:
    - Beige, off-white, warm grey, muted gold accents, charcoal text
- Rounded cards, soft shadows
- Smooth scroll, subtle animations
- Real salon imagery (haircuts, grooming, skincare, interiors)
- Warm, inviting, premium tone

Avoid:
- Loud colors
- Heavy gradients
- Overcrowded text
- Cheap stock photos
- Flashy or outdated styles

---

## Website Structure & Sections

### Hero Section (Booking Trigger — First Screen)

**Purpose:** Immediate premium feel + CTA

Include:
- Full width premium salon image/video background
- Bold benefit-driven headline
- Subtext focusing on hygiene, professionalism, trust
- Primary CTA button: **Book Appointment**
- Secondary CTA: View Services

---

### Services Section (Highly Engaging Service Cards)

Display major services as modern cards with images:
- Haircuts & Styling
- Beard & Grooming
- Facials & Skin Care
- Bridal & Makeup
- Hair Treatments

Each card must contain:
- Service image
- Short 2-line description
- “Starting from ₹…” pricing
- CTA: **Book this service**

---

### Why Choose Us (Trust Builder)

Use icons with short text for:
- Hygienic & sanitized tools
- Experienced stylists
- Premium products used
- Comfortable ambience
- 1000+ happy customers

---

### Gallery / Before-After (Visual Proof)

Grid layout showing:

- Before/after transformations
- Real client results
- Haircuts, beard, facial glow, bridal makeup

This section should make the user imagine their own transformation.

---

### Pricing Preview (Removes Hesitation)

Clean pricing cards:

- Transparent starting prices
- Simple layout
- CTA: **Book Now**

---

### Reviews / Testimonials (Critical for Trust)

Design testimonials like Google reviews:

- 5-star ratings
- Indian names
- Realistic, trust-building feedback
- Clean card layout

---

### Location, Contact & WhatsApp Booking

Include:

- Embedded map
- Address and working hours
- WhatsApp booking button
- Call button
- Booking form

Make booking extremely easy.

---

## Pages Required (Multi-Page Website)

- Home
- Services (individual page for each service)
- Gallery
- About Us
- Contact

---

## Technical Requirements

- Mobile-first responsive design
- Sticky top navigation with “Book Appointment” button
- Smooth scrolling animations
- SEO-friendly HTML structure
- Fast loading performance
- Modern font pairing (e.g., Playfair Display + Poppins)
- Elegant icon set

---

## Tone of the Website

- Premium but friendly
- Professional but warm
- Modern yet culturally fitting for Indian customers

---

## End User Journey

The user should:

> Land on website → Feel it’s premium → See services → See proof → See prices → Trust → Book within 60 seconds.

---

## Important Instruction to the AI

Do **not** create a generic template website.

Design the layout intentionally to:
- Guide attention
- Build trust progressively
- Reduce hesitation
- Increase bookings

This is a **high-end modern salon brand website**, not a generic business site.
