#### BASICS of customers TO REMEMBER BEFORE WRITING : 
(*Make of list of this everytime, before you write even a single word*)
- Age
- Gender
- Problems
- Pains
- Desires
- What action do I want them to take.
- What the email going to be about.

## FRAMEWORKS

1. **PAS** : Problem + Agitate + Solution
2. **HLBO** : Hook + Lead + Body + CTA
	- Body -  story + value
3. **NESB** (not really a framework, but *elements to include in the copy* )
	- New
	- Easy 
	- Safe
	- Big
4. **AIDA** : Attention + Interest + Desire + Action

- ***HOOK*** -  Disrupt , grab attention to read the copy
- ***STORY / VALUE / BODY*** : Intrigue them, make them feel something, lead them down the CTA. 
-  ***OFFER/CTA*** : What to do next ?
