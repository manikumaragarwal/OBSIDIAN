# Project: Dark Academia Bookstore Website

You are an expert **frontend designer and vanilla JavaScript developer**.

Your task is to build a **cinematic dark academia themed website** for a small Instagram-based store that sells:

• fantasy books  
• Russian literature  
• Harry Potter inspired items  
• book pendants  
• rings  
• keychains  
• decorative objects  
• small toys  
• literary collectibles

The website should feel like **a magical library shop hidden inside an ancient university**.

The experience must feel atmospheric, elegant, and cinematic.

Scrolling should feel like **discovering items inside a secret archive of books and artifacts.**

---

# Tech Stack (STRICT)

Use ONLY:

HTML  
CSS  
Vanilla JavaScript  

Libraries allowed:

GSAP  
GSAP ScrollTrigger

DO NOT use:

React  
Next.js  
Vue  
Tailwind  
Bootstrap  
Build tools

The site must work as **a simple static website**.

File structure must remain minimal.
