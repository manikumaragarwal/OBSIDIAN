A curated list of free resources to learn design fundamentals, UX, conversion optimization, AI tools, and modern web development workflows.

# ROADMAP

Alright, I’m going to give you a **real roadmap** — not generic “learn HTML → learn CSS → become designer” stuff.  
This is structured the way someone who **actually builds client websites** (like you already are) should learn — focusing on **conversion + creativity + AI leverage**.

Think of this as leveling up from  
“guy who builds websites” → “guy who designs websites that _make money_”.

---

# 🚀 PHASE 3 — Modern Web Design Patterns (High Conversion Layouts)

Now you learn **what actually converts in client projects**.

---

## 🔥 Core Layouts You MUST master

### 1. Service Business Website (most clients)

Structure:

```
Hero (clear value)
→ Social proof
→ Services
→ Why choose us
→ Testimonials
→ CTA
```

---

### 2. Landing Page (high conversion)

```
Hook
→ Problem
→ Solution
→ Benefits
→ Proof
→ CTA
```

---

### 3. Portfolio / Agency site

```
Hero (identity)
→ Work showcase
→ Process
→ Testimonials
→ Contact
```

# 🚀 PHASE 6 — Real Client Skills (MOST IMPORTANT)

You already experienced this:

> “client keeps asking small changes forever”

So now:

---

## 🎯 Learn THESE skills:

### 1. Scope control

Say:

- 2 revisions free
    
- After that ₹X per change
    

---

### 2. Design before development

Always:

- Show design first
    
- Then code
    

---

### 3. Use AI for communication

Example:

```
"Write a professional message explaining revision limits"
```

---

### 4. Build templates

- school website
    
- coaching website
    
- business landing page
    

👉 Reuse, don’t rebuild.
