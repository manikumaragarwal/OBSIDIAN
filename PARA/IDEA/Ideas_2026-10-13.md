Rules behind the numbers:

- **4 seconds is the shortest Seedance 2.0 Mini will make**, so no clip can be shorter than 4.
- **Dialogue clips are as long as the voice file** (the padded files in `audio/clip-ready/` are exactly these
  lengths). If you change a clip's duration, the voice file has to match, so don't.
- If a clip comes out too short for its action, ask for one second more on that clip only (about 140 credits
  per extra second). The edit can always trim, but it can't add.

## How to build a clip (the whole method)

1. Add a **Video Generator** node. Name it `Clip S03` and so on.
2. Wire it by shot type:
   - **SILENT** (S01, S02A, S02B, S07, S09): still → **START FRAME** port. Nothing in REFERENCES or AUDIO.
     (Spaces won't allow a start frame together with references, so this is the whole wiring.)
   - **DIALOGUE** (S03, S04, S05, S06, S08, S10, S11, S12): still → **REFERENCES**, plus the leo / zara / biko
     Upload nodes of whoever is in the shot → **REFERENCES**, plus the `Sxx-voice` Upload → **AUDIO**.
3. **Type the prompt in the node itself** (leave no Text node on its prompt port). Wherever you see
   `@S03-still`, `@leo`, `@S03-voice` below, type `@` and pick that connected node, so it becomes a chip.
   Name your Upload and still nodes exactly `S03-still`, `S03-voice`, `leo`, `zara`, `biko`.
4. If a clip fails with a vague "blocked" error, retry with plain names ("the lion") instead of `@` chips.

## Should the previous clip feed the next one? No.

- Each clip starts from its own approved still, and the stills already carry the same world, characters and
  light. That IS the continuity.
- Wiring clip N's video or last frame into clip N+1 makes the model copy N's camera, pose and drift, and it
  overrides N+1's own still. Dialogue clips can't take a start frame at all.
- Four things keep clips matching: every clip starts from its still · the same CLIP BIBLE in every prompt ·
  the same model/720p/9:16 · only the characters in the shot as references (more references make Seedance
  average them and drift).
- Cuts: clip N's last frame is rarely identical to still N+1. A different camera is a normal film cut. If a
  pose jumps, trim a few frames in the edit.
