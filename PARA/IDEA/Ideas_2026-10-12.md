## 3b · Doing it in Magnific SPACES (Suresh's ask) → see `ONE-MORE-GAME-spaces-wiring.png`

Hub + selective chain, not a pure daisy chain.

- **7 bible nodes**, made once: Text `style-world` (STYLE + WORLD), Text `CAST`, Image Generator `world`
  (= W00), and Uploads `scale` (TRIO), `leo`, `zara`, `biko`. Give the nodes exactly these names so @leo
  etc. resolve.
- **Every shot generator** gets: `style-world` + `CAST` + its own `Text Sxx` → **prompt** port;
  `world` + `scale` + the characters in the shot → **reference** port. Both ports take many wires.
- **Red chain wire** (previous generator's output → this generator's reference) ONLY on S01B, S03B, S06B,
  S09B, S10B, S12. Chaining all 18 in a row copies each frame's camera and its mistakes into the next.
- `world` (W00) gets `style-world` + `Text W00` only (no CAST). S03M gets `Text S03M` + `leo` only.
- Leave each generator's own prompt box empty (Spaces takes a connected prompt OR an inline one).
- Settings on every generator: Nano Banana 2, 9:16, 2K, Unlimited on, the same seed.
- Run `world` alone first and approve it, then S01A, then the rest. A generator fails if anything wired
  into it has no output yet.
